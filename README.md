# Web Back-End Specialization

![JavaScript](https://img.shields.io/badge/JavaScript-ES6-yellow) ![Python](https://img.shields.io/badge/Python-3.12-blue) ![Node.js](https://img.shields.io/badge/Node.js-%3E=12-green) ![MongoDB](https://img.shields.io/badge/MongoDB-7.0-green) ![Flask](https://img.shields.io/badge/Flask-3.x-lightgrey) ![License](https://img.shields.io/badge/License-Holberton-yellow)

This repository contains the Web Back-End Specialization projects at Holberton School. The curriculum covers a comprehensive range of back-end technologies and concepts, starting from modern JavaScript (ES6) fundamentals, progressing through Node.js server-side development, database management with MongoDB, and extending into Python asynchronous programming and type annotations.

## Sub-Projects

| Project | Description |
|---------|-------------|
| ES6_basic | ES6 syntax fundamentals -- const/let, arrow functions, template literals, spread/rest operators, destructuring, for...of loops |
| ES6_classes | Object-Oriented Programming with ES6 classes -- constructors, inheritance, getters/setters, static methods, Symbol.toStringTag |
| ES6_data_manipulation | Array methods (map, filter, reduce), Set, Map, TypedArrays, ArrayBuffer |
| ES6_promise | Asynchronous programming with Promises -- creation, chaining, error handling, Promise.all, Promise.race |
| NoSQL | MongoDB -- CRUD operations in shell and Python (PyMongo), aggregation, log analysis |
| Node_JS_basic | Node.js fundamentals -- file I/O, HTTP server, Express framework, routing, controllers |
| pagination | API pagination techniques -- simple page-based, hypermedia, deletion-resilient cursor pagination |
| python_async_comprehension | Async generators, async comprehensions, runtime measurement with asyncio |
| python_async_function | Python asyncio -- async/await coroutines, asyncio.gather, create_task, concurrent execution |
| python_variable_annotations | Python type hints -- basic types, typing module (List, Tuple, Callable, Union), variable annotations |
