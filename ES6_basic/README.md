# ES6 Basics

A foundational project introducing modern JavaScript (ECMAScript 2015) features. Each file demonstrates a distinct ES6 concept with reusable, production-style functions.

---

## Tasks / Files

| File | Description |
|------|-------------|
| `0-constants.js` | Illustrates the difference between `const` and `let` for variable declarations. |
| `1-block-scoped.js` | Demonstrates block-scoping with `let` and `const` inside `if` blocks. |
| `2-arrow.js` | Rewrites a standard function as an arrow function. |
| `3-default-parameter.js` | Uses default parameter values in function signatures. |
| `4-rest-parameter.js` | Collects remaining arguments into an array using the rest parameter (`...args`). |
| `5-spread-operator.js` | Expands iterables into individual elements with the spread operator (`...`). |
| `6-string-interpolation.js` | Builds strings with template literals and embedded expressions. |
| `7-getBudgetObject.js` | Uses property value shorthands in object literals. |
| `8-getBudgetCurrentYear.js` | Computes object keys dynamically with computed property names. |
| `9-getFullBudget.js` | Combines property shorthands with arrow functions inside object methods. |
| `10-loops.js` | Iterates over arrays with the `for...of` loop. |
| `11-createEmployeesObject.js` | Builds nested objects using enhanced object syntax. |
| `12-createReportObject.js` | Creates a report object that includes both data and a method, demonstrating full object literal enhancements. |

---

## Key Concepts

- **const / let** -- block-scoped variable declarations vs. traditional `var`
- **Arrow functions** -- concise `() =>` syntax and lexical `this` binding
- **Default parameters** -- function parameters with fallback values
- **Rest / Spread** -- gathering arguments (`...args`) and expanding iterables
- **Template literals** -- backtick-delimited strings with `${}` interpolation
- **Property shorthands** -- `{ name }` instead of `{ name: name }`
- **Computed property names** -- dynamic object keys with `[expression]`
- **for...of** -- clean iteration over iterable values
- **Object method definitions** -- concise method syntax inside object literals
